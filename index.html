How to try it

  1. Open this page on your phone.
  2. Tap the 🎙 and allow the microphone.
  3. Say a command.

On iPad / Safari: transcription falls back to a Cloudflare worker, so voice still works where the browser has no speech recognition.

The 📻 button mutes the radio banter. And if the mic misbehaves, there's a text box — type the command instead.

Prototypes evolve fast; this page just points at them. If something looks stale, it probably is — tell Casey.
